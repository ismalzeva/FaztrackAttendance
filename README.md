# Faztrack Attendance

MVP attendance proof and quantification for field workers.

## M0 scope

- FastAPI modular-monolith backend
- tenant, user, membership, role, project-scope, and audit foundations
- session login/logout/me endpoints
- PostgreSQL production configuration with SQLite test fallback
- Next.js role-based PWA shell using Faztrack brand tokens
- automated tenant-isolation and authentication tests

## M1 scope

- tenant-scoped projects, workers, daily assignments, schedules, and supervisors
- Google Sheets import with five fixed tabs
- preview and full validation before database writes
- confirm operation with code-based upsert and idempotent retry
- import audit trail and responsive Faztrack admin interface

See [`docs/GOOGLE_SHEETS_TEMPLATE.md`](docs/GOOGLE_SHEETS_TEMPLATE.md) for the
required sheet structure.

## M2 scope

- worker login using tenant code, worker ID, and PIN
- EC P-256 device key generated by the PWA
- five-minute, one-time server challenge and signature verification
- supervisor/admin approval and rejection workflow
- one active device per worker with audited replacement

Worker enrollment is available at `/enroll`; approver review is available at
`/devices`. See [`docs/M2_ACCEPTANCE.md`](docs/M2_ACCEPTANCE.md).

## M3 scope

- signed check-in and check-out from the active device
- server time, client capture time, GPS coordinates, and accuracy evidence
- project assignment, working-day, event-order, and duplicate checks
- geofence classification into `VALID`, `REVIEW`, or `REJECTED`
- scoped supervisor review with an immutable audit trail

Attendance capture is available at `/attendance`; exception review is available
at `/review`. See [`docs/M3_ACCEPTANCE.md`](docs/M3_ACCEPTANCE.md).

## M4 scope

- daily timesheet derived from assignments, schedules, and verified attendance
- present, absent, incomplete, exception, and pending states
- late and early-leave quantification with tenant-configurable grace periods
- attendance factor (`present days / scheduled days`) as a future payroll input
- project-scoped supervisor view and immutable, audited period closing

Timesheet review and closing are available at `/timesheets`. Payroll calculation
is intentionally separate. See [`docs/M4_ACCEPTANCE.md`](docs/M4_ACCEPTANCE.md).

## M5 scope

- admin/supervisor login and tenant workspace selection at `/login`
- production containers for PostgreSQL, FastAPI, and standalone Next.js
- environment-only production secrets, automatic migrations, and health checks
- Lumin Park pilot deployment runbook, field UAT, and rollout go/no-go criteria

See [`docs/M5_PILOT_RUNBOOK.md`](docs/M5_PILOT_RUNBOOK.md) before installing the
pilot and [`docs/M5_ACCEPTANCE.md`](docs/M5_ACCEPTANCE.md) for the completion gate.

## Local backend

```bash
cd backend
uv sync --extra dev
uv run alembic upgrade head
uv run uvicorn app.main:app --reload
uv run pytest
```

Set `FAZTRACK_DEMO_SEED_PASSWORD`, then run `uv run python -m app.seed` to create
the optional `admin.demo` account. Never reuse development credentials in production.

## Local frontend

```bash
cd frontend
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE_URL=http://localhost:8000/api/v1`.
