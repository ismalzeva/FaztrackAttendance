## 👷 Untuk Karyawan

### Cara Absen Masuk (CHECK IN)

1. Buka link absensi dari HP: **https://attendance-metro.gofaztrack.com/absen**
2. Masukkan **ID Pekerja** (contoh: `W001`)
3. Masukkan **PIN** (4 digit)
4. Klik **Masuk**
5. Pilih **Lokasi Kerja** (Lavenue atau Pakuwon)
6. Klik **CHECK IN**
7. Izinkan akses lokasi GPS saat diminta
8. Tunggu hingga muncul status **VALID** ✅

### Cara Absen Keluar (CHECK OUT)

1. Buka halaman absensi yang sama
2. Login dengan ID Pekerja & PIN
3. Klik **CHECK OUT**
4. Tunggu konfirmasi

### ⚠️ Yang Perlu Diperhatikan

- **GPS harus aktif** — izinkan akses lokasi di browser
- **Radius absensi: 500 meter** dari titik lokasi kerja
- **1× CHECK IN per hari** per lokasi
- Jam kerja: **07:00 – 19:00 WITA**
- Jika di dalam radius → status **VALID**
- Jika di luar radius → status **REVIEW** (perlu verifikasi manajemen)

## 📊 Untuk Manajemen

### Login Dashboard

1. Buka: **https://attendance-metro.gofaztrack.com/login**
2. Masukkan email & password
3. Klik **Masuk**

### Fitur Dashboard

| Fitur | Keterangan |
|-------|------------|
| **Daftar Karyawan** | Lihat semua karyawan & status aktif |
| **Riwayat Absensi** | Filter per tanggal, lokasi, status |
| **Status Absensi** | VALID / REVIEW / REJECTED |
| **Export Data** | Download laporan absensi |

### Status Absensi

| Status | Arti |
|--------|------|
| ✅ **VALID** | Absensi berhasil, dalam radius |
| ⏳ **REVIEW** | Di luar radius, perlu verifikasi |
| ❌ **REJECTED** | Ditolak oleh sistem |

## 🛠️ Troubleshooting

| Masalah | Solusi |
|---------|--------|
| "Izin lokasi ditolak" | Aktifkan GPS di pengaturan HP & izinkan browser akses lokasi |
| "Sinyal GPS tidak tersedia" | Coba di luar ruangan, pastikan GPS aktif |
| "Bukan jadwal kerja" | Hubungi admin untuk penjadwalan |
| "Gagal mengirim absensi" | Cek koneksi internet, coba lagi |
| Lupa PIN | Hubungi admin |
